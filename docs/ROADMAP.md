# 迭代路线图（供产品负责人排优先级）

## v0.1 ✅ 已完成（MVP）

记账 · 生活费倒计时 · 月度预算 + 分类配额 · 统计复盘 · 深色模式 · CSV 导出 · 无广告纯本地

## v0.2 / v0.3 功能池（按你的判断排序）

| # | 功能 | 说明 / 成本 |
|---|---|---|
| 1 | **分类管理** | ✅ 已完成：增删改自定义分类、选图标与颜色、排序、内置与流水保护 |
| 2 | **AI 智能分类与建议** | 记账时自动识别分类；月末生成消费分析与建议。接 DeepSeek API，需要你自己的 API Key（按量计费，约几分钱/月），可在设置里开关 |
| 3 | **JSON 备份 / 恢复** | ✅ 已完成：一键备份到文件、从文件恢复（带校验与保护） |
| 4 | **周期账单** | ✅ 已完成：订阅/话费/健身卡等固定支出，到期提醒 + 一键入账顺延 |
| 5 | **预算超支通知** | 本地定时通知（不需要服务器） |
| 6 | **桌面小组件** | 倒计时卡片直接放桌面 |
| 7 | **多账户** | 现金 / 饭卡 / 银行卡分开记 |
| 8 | **年视图与日历热力图** | ✅ 已完成：全年 12 月支出柱状图 + GitHub 风格每日支出热力图 |
| 9 | **月报分享卡片** | 生成精美月报图片发朋友圈 |
| 10 | **iOS 版本** | 需要 Mac 或云端构建，成本较高 |
