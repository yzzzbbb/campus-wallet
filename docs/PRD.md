# campus-wallet 产品需求文档（PRD）v0.1 — MVP

> 定位：专为大学生设计的生活费记账 + 预算规划 App。
> 底线：无广告、无登录、无任何网络请求，数据全部存本地。
> 中文名待定（候选：余粮 / 半月 / 月匣 / 钱袋子），由产品负责人 YZB 拍板。

## 1. 核心功能

### 1.1 生活费倒计时（首页核心）
- 用户设置：生活费金额、发放周期类型（`每月固定日` / `每 N 天`）、发钱日（或上次发钱日）。
- 首页大卡片显示三要素：
  - **距下次发生活费还有 N 天**（今天即发钱日 → 显示"今天发生活费！"）
  - **本周期剩余可用金额**（= 本月预算总额 − 本月支出合计，可为负 → 显示"已超支 X 元"）
  - **日均可用**（= 剩余可用 ÷ 距下次发钱天数）
- 点"收到生活费"按钮 → 自动记一笔"生活费"收入 + 按周期规则推算下次发钱日。

### 1.2 记账
- 支出 / 收入两态切换；金额、分类、备注、时间（默认当前）。
- 流水可编辑、可删除；按日分组列表；支持按月切换查看。
- 快速记账：首页悬浮按钮一键进入。

### 1.3 预算规划
- 月度预算总额（默认 = 生活费金额，可手动改）。
- 分类配额：给任意支出分类设月度配额；进度条三档：
  - `<80%` 正常（绿/主题色）
  - `80% ~ 100%` 提醒（黄）
  - `>=100%` 超支（红）
- 首页显示本月剩余预算与超支分类提醒。

### 1.4 统计
- 本月支出分类占比饼图。
- 近 6 个月支出/收入趋势柱状图。
- 月结复盘卡片：总支出、预算完成率、超支分类 Top3。

### 1.5 设置
- 深色模式（跟随系统 / 手动）。
- 数据导出 CSV；清空全部数据（二次确认）；关于页。

## 2. 分类体系（内置）

| 方向 | 内置分类 |
|---|---|
| 支出 expense | 餐饮、日用、学习、交通、娱乐、服饰、医疗、人情、其他 |
| 收入 income | 生活费、奖学金、兼职、红包、其他 |

- 用户可新增、改名、排序；内置分类可改名但不可删除（MVP 简化：内置不可删）。
- 每个分类有：名称、图标（内置图标集）、颜色。

## 3. 决策表（核心计算规则，不可自行推断）

| # | 场景 | 规则 |
|---|---|---|
| R1 | 下次发钱日（每月固定日） | 取设置中的"发钱日 d"：本月 d 日已过 → 下月 d 日；未过 → 本月 d 日（含今天） |
| R2 | 下次发钱日（每 N 天） | 上次发钱日 + N 天 |
| R3 | 剩余可用 | 本月预算总额 − 本月支出合计（不含收入）；可小于 0 |
| R4 | 日均可用 | 剩余可用 ÷ max(距下次发钱天数, 1)，保留 2 位小数；剩余可用 < 0 时显示 0.00 |
| R5 | 倒计时文案 | 距下次发钱 0 天 → "今天发生活费！"；>0 天 → "还有 N 天" |
| R6 | 分类配额进度 | 该分类当月支出 ÷ 该分类配额；未设配额不显示进度 |
| R7 | 预算总额 | 未手动设置时 = 生活费金额（未设生活费时引导用户设置） |
| R8 | 收到生活费 | 记收入"生活费"，amount = 设置的生活费金额，时间 = 现在；随后按 R1/R2 重算下次发钱日 |
| R9 | 流水删除/编辑 | 所有衍生数值实时重算，不做缓存 |
| R10 | 统计口径 | "本月"= 自然月（1 日至月末）；收入只进收入统计，不抵扣支出 |

## 4. 数据模型（SQLite）

- `categories(id INTEGER PK, name TEXT, type TEXT CHECK(type IN ('expense','income')), icon TEXT, color INTEGER, sort INTEGER, builtin INTEGER)`
- `transactions(id INTEGER PK, type TEXT, amount_cents INTEGER, category_id INTEGER, note TEXT, occurred_at TEXT ISO8601, created_at TEXT ISO8601)`
- `settings(key TEXT PK, value TEXT)` — 键：`allowance_amount_cents` / `allowance_period_type`(`monthly`|`every_n_days`) / `allowance_pay_day` / `last_pay_date` / `monthly_budget_cents`（可缺省）
- `category_budgets(id INTEGER PK, category_id INTEGER, month TEXT 'YYYY-MM', limit_cents INTEGER)`

**金额一律以"分"（整数）存储，界面显示两位小数。时间存 ISO8601 字符串。**

## 5. 页面结构

- `MainShell`：底部导航 4 Tab —— 首页 / 流水 / 统计 / 我的
- 首页：倒计时大卡片 + 本月概览 + 今日流水 + FAB 记账
- 记账页：全屏弹层（支出/收入切换、金额、分类网格、日期、备注）
- 流水页：月份切换 + 按日分组列表 + 编辑/删除
- 统计页：饼图 + 趋势 + 复盘卡片
- 预算规划页：从首页卡片点击进入（月度总额、生活费周期设置、分类配额列表）
- 设置页：深色模式、导出、清空、关于

## 6. 技术栈与约束

- Flutter stable（Dart 3），状态管理 provider，存储 sqflite，图表 fl_chart，格式化 intl
- Android 优先；**禁止引入任何网络请求依赖**（纯本地）
- 应用包名 `com.yzb.campus_wallet`，支持中文界面（语言文件或直接中文字面量均可，MVP 直接中文字面量）
