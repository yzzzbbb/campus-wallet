# 生活费账本（campus-wallet）

专为大学生打造的生活费记账 + 预算规划 App。

**无广告 · 无登录 · 无联网 · 数据全部保存在本机**

## 功能

- 🎯 **生活费倒计时**：距下次发生活费还有几天、剩余可用、今天还能花多少
- 📝 **快速记账**：支出/收入、内置大学生分类（餐饮/日用/学习/交通/娱乐…）、备注、日期
- 🗂️ **精细预算**：月度总额 + 按分类配额，进度条三档预警（正常/提醒/超支）
- 📊 **统计复盘**：分类占比饼图、近 6 月收支趋势、年度支出柱状图、日历热力图、超支分类 Top3、月报图片导出
- 🏷️ **分类管理**：自定义分类增删改、图标与颜色、排序（内置分类与有流水的分类受保护）
- 💾 **备份/恢复**：一键导出完整 JSON 备份、换机恢复，数据不丢
- 🔁 **周期账单**：订阅、话费、健身卡等固定支出，到期提醒 + 一键入账自动顺延
- 🔔 **预算提醒**：打开应用自动检查预算使用率，超 80% 或超支时本地通知（可开关，无服务器）
- 🌙 深色模式、CSV 数据导出、一键清空

## 技术栈

- Flutter（Dart 3）+ Material 3
- provider 状态管理 / sqflite 本地存储（金额以分存储，无浮点误差）
- fl_chart 图表 / intl 格式化
- 核心计算规则（倒计时、剩余可用、日均可用、配额进度）全部为纯函数，有单元测试覆盖

## 构建

```bash
# 依赖（国内网络建议配置镜像）
flutter pub get
# 测试
flutter test
# 打包 debug APK（无需签名，可直接装真机）
flutter build apk --debug
```

> Android Gradle 仓库已内置阿里云镜像，国内网络可直接构建。

## 目录结构

```
lib/
  core/       数据模型、SQLite、决策表纯函数、主题（契约层）
  state/      Provider 状态管理
  widgets/    共享组件（分类图标、金额显示）
  features/
    home/          首页（倒计时卡片、到期提醒）
    transaction/   记账 + 流水
    budget/        预算规划
    stats/         统计
    bills/         周期账单
    settings/      设置（分类管理、备份恢复）
docs/         PRD 与架构契约
```
